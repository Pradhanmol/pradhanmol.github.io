## 🆘 Troubleshooting

### **If images don't show:**
1. Check browser console (F12)
2. Hard refresh: `Cmd+Shift+R` (Mac) or `Ctrl+Shift+R` (Windows)
3. Check gh-pages branch has `images/` folder

### **If site doesn't load:**
1. Check GitHub Pages status: repo Settings → Pages
2. Check GitHub Actions for errors: repo → Actions tab
3. Wait 2-3 minutes (sometimes takes longer first time)

- ✅ Already fixed with `.nojekyll` file
