### **Step 3: Deploy (8 minutes)**

Choose your deployment method:

#### **Option A: GitHub Pages (Recommended)**

```bash
# 1. Install gh-pages package
npm install --save-dev gh-pages

# 2. Add deploy scripts to package.json (manually add these lines to the "scripts" section):
"predeploy": "npm run build",
"deploy": "gh-pages -d dist"

# 3. Deploy with one command
npm run deploy
```

**Then:**
1. Go to your GitHub repo settings
2. Navigate to "Pages"
3. Select source: `gh-pages` branch
4. Wait 2-3 minutes
5. Visit: `https://pradhanmol.github.io`

---

#### **Option B: Vercel (Easiest, 3 minutes)**

```bash
# 1. Install Vercel CLI
npm i -g vercel

# 2. Deploy
vercel

# Follow prompts:
# - Login to Vercel
# - Link to project
# - Deploy
```

You'll get an instant preview URL like: `https://your-portfolio-xxxx.vercel.app`
